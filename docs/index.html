Button

Primary는 화면당 하나의 주요 행동에만 사용합니다. 위계에 따라 Secondary, Tertiary, Ghost를 선택하세요.

<button class="ds-btn">Primary</button>
<button class="ds-btn ds-btn--secondary ds-btn--sm">Secondary</button>
<button class="ds-btn" aria-busy="true">저장</button>

Form

레이블은 항상 표시하고, 오류는 aria-invalid와 설명 텍스트로 함께 전달합니다.

실명을 입력해주세요.
올바른 이메일 형식이 아닙니다. 
<div class="ds-field">
  <label class="ds-label" for="email">이메일</label>
  <input class="ds-input" id="email" aria-invalid="true" />
  <span class="ds-error">올바른 이메일 형식이 아닙니다.</span>
</div>

Checkbox · Radio · Switch

네이티브 input을 그대로 사용하므로 키보드·스크린리더 접근성이 보장됩니다. Switch는 즉시 적용되는 설정에 사용합니다.

<label class="ds-check"><input type="checkbox" /> 이용약관 동의</label>
<label class="ds-switch"><input type="checkbox" role="switch" /> 알림 받기</label>

Card

관련 콘텐츠를 하나의 단위로 묶습니다. 기본(테두리), Elevated(그림자), Interactive(호버) 변형이 있습니다.

Modal · Toast · Tooltip

Modal은 네이티브 <dialog>를 사용해 포커스 트랩과 Esc 닫기를 기본 제공합니다. Toast는 DS.toast()로 띄웁니다.

<button class="ds-btn" data-ds-open="my-modal">열기</button>
<dialog class="ds-modal" id="my-modal">…<button data-ds-close>닫기</button></dialog>

DS.toast("저장되었습니다");
